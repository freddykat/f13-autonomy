# Collaboration Map

The project is easier to contribute to when each discipline has a clear entry point.

## ZF / transmission specialists
Useful contributions:
- 8HP70/75/8P70/8P75 measurements;
- K0 internals;
- oil-pump control;
- clutch capacity;
- parts interchangeability;
- ATC output interface data.

Start with issues #55, #56 and #58.

## BMW controls / calibration specialists
Useful contributions:
- MSD85_HY logs;
- torque-model messages;
- EME/EGS/DME coordination;
- start/stop semantics;
- xDrive / VTG integration;
- F-series plausibility logic.

Start with issue #57.

## EV / OpenInverter / VCU developers
Useful contributions:
- GA8P75HZ control;
- torque arbitration;
- K0 sequencing;
- auxiliary oil-pump logic;
- bench/HIL strategy;
- BMS/VCU architecture.

## Battery engineers and suppliers
Useful contributions:
- high-energy pouch-cell selection;
- module mechanical design;
- cooling;
- BMS;
- HV isolation;
- propagation protection;
- certification and validation.

See BATTERY_PARTNER_RFI.md and issue #59.

## CAD / mechanical contributors
Useful contributions:
- transmission case scan;
- bellhousing and AWD output measurement;
- F13 rear-body scan;
- structural battery enclosure;
- thermal plate routing.

## Why contribute?

The interesting part of this project is not simply “more power.”

It is an attempt to make a V8 grand tourer genuinely practical as a daily commuter:
- EV for routine commuting;
- V8 for range, sound and character;
- electric torque for response and regeneration;
- BMW xDrive and chassis systems retained where possible.

The project is deliberately documented so useful findings can be reused by other BMW retrofit projects.
