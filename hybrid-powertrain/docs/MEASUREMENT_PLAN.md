# Transmission Measurement Plan

## Donors
A. F13 GA8HP70X N63
B. GA8HP75X N63 donor
C. GA8P75HZ / 8P75XPH PHEV donor

## Front-interface measurements
Use crankshaft centerline as the common datum.

- bellhousing bolt coordinates;
- dowel positions and diameters;
- crank pilot diameter;
- crank flange plane to transmission mating plane;
- crank flange plane to K0 input;
- damper/flexplate OD and pattern;
- K0 input spline count and diameters;
- hybrid-module pilot diameter;
- rotor bearing positions;
- oil-feed positions;
- coolant-port positions.

## Main-case measurements
- overall length;
- maximum e-machine housing width/diameter;
- sump depth;
- crossmember position;
- HV and LV connector positions.

## AWD output measurements
For F13 ATC35L and PHEV donor:
- output spline count and diameters;
- engagement length;
- pilot diameter;
- transfer-case bolt circle;
- flange face to shaft end;
- input-shaft length;
- rear-housing depth.

## Documentation rules
For every measurement:
- photo showing datum;
- units in mm;
- uncertainty;
- ZF tag photographed;
- donor model/year.

## CAD deliverable
Start with simplified STEP envelopes:
- bellhousing/front module;
- main case;
- rear output;
- transfer case.

Only model detailed internals after the interfaces are proven.
